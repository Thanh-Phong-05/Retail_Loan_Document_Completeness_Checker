# Retail_Loan_Document_Completeness_Checker
Hệ thống kiểm tra tính đầy đủ của hồ sơ vay vốn là một hệ thống được thiết kế để tổ chức tài liệu đăng ký vay vốn, kiểm tra tính đầy đủ của hồ sơ, xác định hồ sơ còn thiếu hoặc không thể sử dụng và cung cấp kết quả đánh giá mức độ sẵn sàng để nhân viên ngân hàng xem xét. Hệ thống sử dụng Camunda 8 làm nền tảng điều phối quy trình bắt buộc.
